# Support

OpenStreamAlert is community-supported pre-release software.

Before opening a new issue, check the
[troubleshooting guide](docs/TROUBLESHOOTING.md) and search existing
[issues](https://github.com/ericflo/openstreamalert/issues) and
[discussions](https://github.com/ericflo/openstreamalert/discussions).

- Use **Discussions** for setup questions, theme ideas, and showing what you
  made.
- Use the **bug report** issue form for reproducible defects. Remove Twitch
  credentials, private overlay URLs, and personal chat data from screenshots or
  logs.
- Use the **feature request** issue form for product proposals. The current
  scope deliberately prioritizes excellent Twitch chat in OBS over a broad
  multi-platform overlay editor.
- Use [private vulnerability
  reporting](https://github.com/ericflo/openstreamalert/security/advisories/new)
  for suspected security problems. Never disclose them in a public issue.

There is no guaranteed response time for general support. Security reports
follow the acknowledgement target in [SECURITY.md](SECURITY.md).
